# Product

## Register

product

## Users

SCPA serves Indonesian students, early-career job seekers, and professionals who need to understand which roles match their current profile, which skills are missing, and what career actions should come next. Secondary users include thesis/demo evaluators who need to see reproducible evidence that the recommendation pipeline behaves correctly.

## Product Purpose

SCPA is an AI-based career recommendation system that combines job data, user profiles, SBERT semantic matching, NCF interaction scoring, DQN career milestones, and hybrid aggregation. Success means users can move from profile to recommendations to job detail to skill gap without confusing loading states, shallow explanations, or low-context data.

## Brand Personality

Precise, evidence-led, and practical. The interface should feel like a reliable career intelligence tool: restrained enough for focused work, clear enough for demo evaluation, and specific about why a job or skill action is recommended.

## Anti-references

Do not make the product feel like a generic job board with decorative AI labels. Do not rely on route-load success as proof of product quality. Avoid shallow one-line job details, sparse skill suggestions, vague recommendation reasons, permanent spinners, and UI states that blame the user for stale or canceled requests.

## Design Principles

- Prove user outcomes, not just page loads.
- Show fit, evidence, and gaps in the same workflow.
- Prefer stable task UI over decorative motion.
- Make loading, retry, empty, and degraded states truthful.
- Preserve data depth so model output and user explanations stay meaningful.

## Accessibility & Inclusion

Default to WCAG 2.1 AA expectations for contrast, keyboard access, focus visibility, and readable text. Respect reduced-motion preferences. Keep Indonesian user-facing copy clear, specific, and actionable, with English technical terms only where they are the expected skill or role vocabulary.
